# SENTINEL — 安全研究终端

参考终端视频设计的安全研究工作台前端，使用原生 HTML、CSS 和 JavaScript，无需安装依赖。

## 本地查看

下载仓库后双击 `index.html`，或使用独立文件 `SENTINEL-terminal.html`。所有静态资源均为本地文件，无需联网加载字体。

## 动态工作流程

48 秒六阶段演示：范围确认 → 变更分析 → 独立复核 → 沙箱验证 → 证据整理 → 人工确认。左侧逐字输出研究文档并标注关键行，右侧按阶段出现彩色旁注。支持暂停、继续、重播、阶段跳转、拖动进度、1×/2×/4× 倍速与专注模式。所有验证记录都是预设样本，不会进行网络扫描。

## 功能

- 模拟实时研究日志，支持暂停、继续和清空。
- Claude / GPT / Gemini 三模型协作旁注。
- 示例授权目标与研究任务创建。
- 漏洞队列、优先级筛选、详情及人工复核状态。
- 报告 Markdown、事件日志 JSON 和赏金账本 CSV 导出。
- Ctrl+K 命令面板，支持手机布局。

终端命令：`help`、`status`、`targets`、`findings`、`pause`、`resume`、`clear`、`export`。

## 文件

- `index.html`：页面结构。
- `style.css`：终端风格与响应式样式。
- `app.js`：交互、演示数据与本地状态。
- `workflow.js`：确定性的流程播放与阶段控制。
- `workflow.css`：动态正文、标注、旁注和播放控制样式。
- `SENTINEL-terminal.html`：内嵌 CSS/JS 的独立版本。

## 视频对应的六个模块

视频提供六个可视化面板，并未列出六个 AI 模型。本版按其布局加入紫黑色六联屏，保留三模型协作角色。

| 视频面板 | 产品模块 | 输入 | 输出 |
| --- | --- | --- | --- |
| Obsidian Vault | 研究知识库 | 授权规则、代码、公告、历史记录 | 资料索引与版本关系 |
| Brain.py Readout | 研究调度器 | 资料变更、范围与优先级 | 研究任务、节点分配与状态 |
| Obsidian Core | 多模型推理核心 | 代码上下文与研究假设 | 分析、反例、待补充证据 |
| Fake Quote Scan | 证据核验台 | 引用、代码位置、版本、测试记录 | 可追踪证据与缺失项 |
| Workstation | 执行工作台 | 任务与人工复核意见 | 日志、状态与报告草稿 |
| Obsidian Graph View | 研究关联图谱 | 目标、假设、证据、报告 | 关联路径与知识回流 |

Claude 负责分析，GPT 负责独立复核，Gemini 负责证据整理；这些是本项目的角色设计，三者均未实际连接 API。每个模块可点击“职责 / I·O”查看详细分工和边界，也可跳转对应演示阶段。

知识网络、旋转核心、证据矩阵与关系图随播放状态变化。实际漏洞需要授权复现与人工确认；实际赏金由项目规则及审核决定。本版没有访问交易所、执行真实测试或提交报告。

本次通过 18 项浏览器交互检查及手机宽度检查。

## 双视图与项目指南

工作台新增三种体验入口：

1. 六联终端：紫黑色高密度可视化控制台。
2. 研究阅读台：参考第一段视频的暖黑正文、行号、逐段高亮和彩色侧边批注。完整示例研究文档随六阶段演示推进，支持暂停、倍速、进度跳转和重播。
3. 项目与操作指南：解释项目定位、核心模块、收入产生条件、六步操作路径、当前可用功能与后端待接入能力。操作步骤提供直接跳转。

完整路径：选择授权项目 → 建立资料上下文 → 分析与独立复核 → 授权环境验证影响 → 人工确认并导出草稿 → 按项目指定渠道提交并跟踪结果 → 复盘回写知识库。

当前没有真实资料上传、模型连接、扫描执行或报告外发。所有研究材料、目标和收益均为演示。新增体验与已有功能共通过 33 项浏览器交互检查。
